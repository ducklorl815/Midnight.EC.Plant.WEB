# 視覺系統：工具感殼層＋青綠強調色＋核心路徑先套齊

我們要大改畫面風格，但仍留在 Bootstrap 骨架上，不重寫前端框架。目標體驗是「清晰工具感」（大觸控、高對比、少裝飾），並用分區讓照片牆可以更編輯／展陳。

**色彩**：淺底＋墨绿作為品牌／成功／結構色；**單一強調色為天藍／青**，專職主 CTA 與「該做」狀態，避免與品牌綠搶同一語義。

**裝飾**：產品名維持「我的植栽」；emoji 僅少量用於 brand 與空狀態；其餘狀態靠色與文字。

**字體**：本輪以系統無襯線與字級層次為主，不先鎖品牌網字。

**交付邊界**：先定 tokens 與共用元件，並套完核心路徑（Layout、首頁、詳情、新增／確認物種、編輯相關頁）；Admin／Settings 只接 tokens，版面不求與前台同級。新增植栽流程要一併理順步驟感與空狀態，但不做成大型多步 wizard。

**詳情資訊順序**：第一屏以記澆水／今日紀錄為主 CTA（hero 只保留精簡狀態）；其下為照片與日記 → 照護紀錄 → 提醒 → 知識／環境 → 進階（同步 API 等）。

## Considered Options

- 延續並精煉現有綠主題：成本低，但難達到「大改」與照片牆編輯感
- 強調色用暖橘／琥珀：行動更跳，但與現有澆水藍語意距離大；最終選青綠以贴近既有「澆水」掃讀習慣
- 本輪全站含 Admin 打磨到同一水準：範圍過大，稀釋核心路徑

## Consequences

之後加頁應先問：這是「任務」還是「展陳／閱讀」？任務用強調色與大觸控；展陳用圖、留白與字級，而不是再堆 badge 與 emoji。
