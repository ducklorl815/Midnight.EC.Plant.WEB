# 新增植栽合併實際環境，確認物種後一次打 AI

新建流程曾是「基本資料 → 確認物種 → 詳情 → 再補實際環境」，導致物種知識 AI 在環境未齊時就跑，之後存環境又打適配 AI。我們決定改為「基本＋實際環境（六項必填）→ 確認物種 → 詳情」：確認前先同步物種知識以比對落差，有落差須勾選「我知道」才建檔；建檔後再打環境適配。詳情頁不再因知識稀疏自動同步。

## Considered Options

- 確認物種後強制多一頁「補環境」再建檔：步驟更清楚，但多一跳
- 維持分頁、僅延後 AI：仍要事後補環境，入口重複

## Consequences

新增流程不再收集位置備註（與實際位置類型易混淆）；`Plant.Location` 仍可在編輯頁填寫。略過物種建檔時保存環境但不打 AI。日後改環境仍用「編輯實際環境」專頁。確認物種建檔時一律強制外部同步／AI 補足（與詳情頁同步同格式），不因物種知識已存在而跳過。
