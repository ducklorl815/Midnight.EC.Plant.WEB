# 照片牆滿版瀏覽與可編輯版面（v1 → v1.1）

首頁照片牆要從「自動雜誌網格＋說明文案」改成「滿版展陳、可手動排版」。任務區不再佔第一屏大塊，編輯能力放在設定內的獨立頁，版面整份 JSON 存 DB。

**殼層（v1.1 修正）**：頂欄保留品牌與導覽（首頁／新增植栽／設定），與其他頁一致；**不再**使用牆上右上浮層按鈕（實測過醜，暫回 Header，日後再調）。

**首頁任務**：今日行動／待補收成牆上方極窄提示條，點開才展開（修正 ADR 0001「上方大塊任務區」的預設形態）。

**編輯入口**：設定 →「照片牆版面」→ 獨立滿版編輯頁；首頁純瀏覽。

**版面模型**：固定欄數軌道網格；每格 `order`、`colSpan`／`rowSpan`（≥1，無硬上限；寬超過欄數則自動加欄）。跨列加高只撐高該格。新盆 append 1×1；刪盆移除後後方依序補位。

**縫寬**：整牆預設 `gapX`／`gapY` 與 `colGaps[]`／`rowGaps[]` 逐條覆寫；數值為 ≥0 px，**無硬上限**（之後若要再定）。編輯用數字框，非 0–48 滑桿。

**取景（v1.1）**：編輯牆滾輪／數字自由 scale（僅 &gt;0）；框內 `overflow:hidden` 可裁切；縮小則 contain＋靠左下留白；存 `zoom`／`focusX`／`focusY`。

**暱稱（v1.1）**：桌機預設隱藏，`:hover`／`:focus-within` 淡入淡出；手機不常駐暱稱，點圖進詳情。

**持久化**：`PhotoWallLayout` 表存單份 `LayoutJson`。無存檔時以封面優先、最近視覺活動排序種子。

**仍屬 v2**：左右斜切／梯形（`diagonals[]`）；上下斜切不做。

## Explored Branches（v1.1 grill）

| 問題 | 選項 | 決定 |
|------|------|------|
| 縫能否逐條調 | 提前 col/rowGaps；維持統一；僅改文案 | 提前逐條縫＋手柄→側欄滑桿 |
| 格內放大位移 | 編輯取景參數；首頁也捏；裁原圖 | 編輯取景參數，不改檔 |
| 新增／設定位置 | 回完整 Header；精簡兩鈕；圖示 | 回完整 Header，去浮層 |
| 暱稱 | 桌機 hover／手機無字；常駐；手機底條 | 桌機 hover；手機無常駐暱稱 |
| 逐條縫 UI | 點縫手柄＋側欄；側欄列全部；只拖縫 | 點縫手柄＋側欄滑桿 |

## Considered Options

- 全站右側常駐 Sider：導覽一致，但改動面大
- 首頁當場編輯模式：易誤觸
- 牆上浮層指令：已試用，視覺差，改回 Header
- 裁切覆寫封面：不可逆，否決

## Consequences

- ADR 0001 的自動雜誌分級僅作無存檔種子；有存檔依牆版面。
- JSON tile 增 `zoom`／`focusX`／`focusY`；layout 增可用的 `colGaps`／`rowGaps`。
- 實作下一刀：Header 還原、caption hover、編輯取景、逐條縫手柄。
