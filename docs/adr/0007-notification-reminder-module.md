# 首頁以「通知提醒」模組承接逾期智慧提醒

模組拼圖首頁需要可見的催辦，又不想無事時佔版面。我們新增 Page Composer 模組「通知提醒」：資料來源為既有智慧提醒（`PlantReminder`），**僅列出已逾期的澆水／施肥**；點列進詳情，並提供一鍵完成（寫今日照護紀錄並 sync）；無項目時整段不渲染。舊「今日行動」提示條不再作為拼圖首頁主入口。

AI 異常預警、AI 分析建議、健康度等屬日常觀察，留在詳情「智慧提醒」／分析結果，不進首頁通知提醒。

## Considered Options

- 固定嵌在殼層、不進拼圖：首頁永遠有位，但破壞「模組可開關／排序」
- 顯示全部 Active（含到期前 2 天、含 AiAlert／Analysis）：較吵，與「可執行催辦」不符
- 模組上只連詳情、不做已澆水／已施肥：少一次完成路徑，站著照顧變慢
- 今日行動與通知提醒兩套並存：用語與入口重複
- 首頁也列 AI 異常：與一鍵照護搶注意力；改為詳情觀察

## Consequences

詳情頁「智慧提醒」仍可顯示並略過 AI 異常；sync 仍產生 AiAlert。通知提醒不提供略過。版面 Normalize 會自動插入此模組（Banner 後），使用者仍可關或刪。
