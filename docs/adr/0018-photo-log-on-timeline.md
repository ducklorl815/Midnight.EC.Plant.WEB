# 記一筆是一次拍照，時間軸看得到照片

ADR-0003 讓時間軸只列澆水／施肥／備註，照片不進軸，避免和照片牆重複。澆水施肥打卡已由 ADR-0017 拿掉；軸上若仍不放照片，就只剩備註。

我們決定記一筆是該盆的一次拍照：一個日期、一段可選備註、一張或多張照片。沒有照片不算一筆。同一天分兩次拍是兩筆；同一次的多張是一筆。時間軸由新到舊列出記一筆並顯示縮圖。相簿是這些照片的平鋪，新照片只從記一筆進來。照片找種的臨時上傳不寫進記一筆。早於這個規則、沒掛記一筆的舊照片留在相簿，不自動編成記一筆。畫面不再讀舊的澆水／施肥打卡。

## Considered Options

- 時間軸繼續不放照片（ADR-0003；澆水施肥拿掉後，軸上沒有可看的紀錄）
- 把舊照片逐張編成記一筆（會捏造當時不存在的一次拍照）
- 相簿另留一條不掛記一筆的新上傳（同一張圖會有兩種身分）

## Consequences

取代 ADR-0003「時間軸不放照片」。照片牆仍是封面排版，不是第二份時間軸。

手機殼可用相機，或從手機相簿把多張補進同一筆。瀏覽器以選檔記一筆。日期預設今天，可改成過去。日期與備註可事後改，不可把該筆照片刪到零張。刪除整筆則照片一併刪；封面或 Banner 若引用被刪的圖，回到占位。沒掛記一筆的舊照片可在相簿單獨刪除。
