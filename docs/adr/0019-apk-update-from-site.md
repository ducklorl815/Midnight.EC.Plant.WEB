# APK 啟動時下載較新的安裝檔

內容已由 ADR-0016 隨網站更新。殼或相機變了，已安裝的手機才需要新的 APK。Study 的手機沒有安裝檔自更新。

我們決定 App 開啟時向同一個植栽網站要版本清單；安裝包比較舊就下載 APK，交給 Android 安裝。`npm run app` 產出 APK，手機接上就安裝並打開。日常這包的 WebView 指向本機網站；放到網站供下載的那包指向已部署的網站。兩包同一把正式簽章，金鑰不進 git。

## Considered Options

- 只靠網站更新、永不換 APK（殼或相機的修正到不了已安裝的手機）
- 用會換來換去的除錯簽章（金鑰一換就蓋不過去，線上更新會斷）

## Consequences

使用者須允許安裝未知來源。沒有網路時，沿用手機上現有的殼，但網站內容仍打不開（ADR-0016）。
